## Shared factual boundaries

- Verified product numbers: 4 trigger-key choices, viewer zoom up to 10x, and optional local 4x enhancement.
- Enhancement uses Real-ESRGAN locally, with speed-first and quality-first modes and a configurable maximum processing size.
- “0 uploads” always means no image-pixel uploads to a cloud AI service for enhancement; it does not describe how the source website serves an image.
- Current price and availability must be verified on the official Chrome Web Store listing.
- Do not claim permanent free pricing, every-site or every-browser compatibility, malware safety, user counts, ratings, speed or quality benchmarks, or verified Amazon/DeviantArt support without dated evidence.
